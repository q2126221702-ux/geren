# 题域引擎 1.0.7 补丁更新

应用内显示的版本号仍为 1.0.7，本次补丁包含：

- 修复 AI 学情分析点击后可能没有反馈的问题，点击后立即显示分析状态，失败时显示提示。
- 修复滚动结果页面或切换题目筛选时，AI 请求和分析结果可能丢失的问题。
- 优化单题 AI 解析按钮的等待提示，避免重复点击发送多个请求。
- 修复站点默认 AI 模式可能携带个人 API Key 的问题。
- 修复首页下拉时顶部出现白条、内容被遮挡的问题。
- 支持同版本补丁检查，安装本次补丁后不会重复提示同一个更新。

从相同签名的正式版覆盖安装会保留学习记录、错题和收藏。手机上原来的 1.0.7 可在“我的 → 设置 → 检查更新”下载本次补丁。
